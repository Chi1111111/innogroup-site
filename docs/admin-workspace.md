# Admin 功能与逻辑地图

## 页面与职责

| 路径 | 页面 | 职责与保存方式 |
| --- | --- | --- |
| `/admin` | 工作台 | 日常业务流程和模块入口；不请求业务数据、不生成虚构统计 |
| `/admin/crm` | 客户与订单 | 客户线索、跟进阶段、订单、代步车；自动保存云端并缓存本机 |
| `/admin/crm?view=orders` | 订单视图 | 可直接进入、刷新和使用浏览器返回；`loanCars` 为代步车视图 |
| `/admin/contracts` | 合同管理 | 状态看板、合同库、编辑与发送；创建、保存、签署链接、邮件与签署状态 |
| `/admin/invoices` | 发票管理 | 发票库、编辑预览、从合同导入、保存、邮件和 PDF；云端/本机模式沿用原配置 |
| `/admin/weekly-reports` | 周报发布 | 期数、摘要、推荐车辆、实际到港、业务动态、市场观察与预告；沿用自动保存队列 |
| `/admin/partners` | 合作伙伴 | 资料、联系方式、Logo 上传；手动保存到当前浏览器，仅用于本机预览 |
| `/admin/japan-market` | 日本车源 | 采集总览、车源报价、历史记录；读取已发布快照，扫描按钮提交采集任务 |

`/admin` 原来显示合作伙伴表单，现在显示工作台，合作伙伴迁移至 `/admin/partners`。其余业务 URL 保留。

## 代码分层

- `AdminAuthGate.tsx`：登录表单、校验会话、监听会话变化。未通过认证时不显示后台内容。
- `AdminLayout.tsx`：公共侧栏、面包屑、网站预览、退出、手机菜单及打印时隐藏公共界面。
- `adminNavigation.ts`：唯一的模块分组、名称、路径、说明；侧栏和工作台共用。
- `AdminDashboard.tsx`：流程导航和模块入口。
- `AdminPartners.tsx`：从原 `AdminVehicles.tsx` 分离的合作伙伴状态、校验、上传和表单。进入合作伙伴不再初始化周报状态。
- `AdminVehicles.tsx`：仅负责周报，不再通过 `mode` 混合伙伴管理。
- `useAdminCrm.ts`：客户资料读取、本机缓存、云端串行写入、错误提示和重试。
- `adminCrmModel.ts` / `adminVehiclesModel.ts`：保留业务转换、默认值和校验；`*Fields.tsx` 保留字段组件。
- `lib/contracts.ts` / `lib/invoices.ts` / `lib/adminApi.ts`：保留现有持久化与认证边界。
- `admin.css`：仅作用于后台工作空间；原业务文档样式保留。

## 跨模块流程

1. CRM 记录线索和跟进阶段。
2. 合同页创建并发送合同；CRM 定期读取已签的购车合同，并合并为订单，保留原有合并规则。
3. 发票编辑器由管理员选择合同，将客户、车辆和金额带入，核对后保存或发送。
4. CRM 更新订单的付款、运输和合规阶段。到港且具备车辆照片时可以同步到周报；缺照片时显示提示。
5. 周报将推荐车辆与实际到港分别维护，并提供前台预览。
6. 日本车源采集独立于上述交易流程，页面展示已发布数据，不能把快照当作实时运行进度。

## CRM 保存规则

- 首次云端读取成功后才启用编辑与合同同步；读取失败时允许导出本机资料、重试读取，不上传缓存覆盖未知的云端状态。
- 云端没有记录时使用既有本机缓存作为初始资料；云端有记录时以云端为准。
- 保存依次进入一个跨组件挂载的队列，防止慢请求在较新请求之后覆盖数据；重新进入页面先等待已有队列再读取。
- 保存中、已保存、失败为不同状态；只有成功响应才显示已保存。失败时可重试当前内容。
- 本机缓存写入错误会被捕获，避免存储限制导致白屏；保存未完成或失败时关闭页面会提示。
- 现有 API 是整份 CRM 写入；跨设备同时编辑的版本冲突仍需服务端版本控制。本次重构未修改数据库协议。

## 验证

`npm run typecheck`、`npm run lint`、`npm test`、`npm run build`。

本地启动 `npm run dev -- --host 127.0.0.1 --port 5173` 后执行 `node scripts/verify-admin-workspace.mjs`：

- 检查所有后台路径、未登录拦截、退出、后台 noindex。
- 检查桌面和手机无整页横向溢出、手机导航、打印隐藏公共导航。
- 模拟 CRM 读取失败，验证暂停编辑且不写入；模拟保存失败、重试成功及串行写入。
- 所有远程请求被模拟或拦截，不发送邮件、不执行真实采集、不修改真实客户数据。
- 截图保存于 `tmp/admin-review/`。

合作伙伴目前并无面向所有访客的云端发布能力，界面已明确显示本机预览范围。邮件、真实签署、付款与真实采集的外部服务结果不属于这次隔离浏览器检查的覆盖范围。
